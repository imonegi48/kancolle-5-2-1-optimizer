# 5-2-1 噴進弾幕装備最適化

74式電子観測儀からコピーできる以下の2データを使う、ブラウザ完結型の装備配分ツールです。

- DeckBuilder v4形式の編成JSON
- 「艦隊分析装備へコピー → 全」の全所持装備JSON

### 所持装備データの保存

74式の「艦隊分析装備へコピー → 全」で取得した所持装備JSONは、正常なJSONとして一度貼り付けるとブラウザのIndexedDBへ自動保存します。次回アクセス時には自動復元されるため、毎回コピペする必要はありません。保存データはGitHub Pagesや外部サーバーへ送信しません。画面の「保存済み所持装備を削除」からブラウザ保存だけを削除できます。


## 最初に：マスターデータ設定（初回のみ）

艦ID・装備IDを、艦名・艦種・対空値・装備カテゴリ・装備可否に変換するためにStart2マスターデータを使用します。

**GitHub Pages側にはStart2や加工済み `master.json` を置きません。** 利用者本人が公開APIのJSONをブラウザで開いてコピーし、このツールへ読み込ませます。読み込んだデータはその利用者のブラウザ内（IndexedDB）だけに保存されます。

初回操作は次の2ステップです。

1. 画面の **「① マスターJSONを開く」** を押す
2. 開いたJSONページで `Ctrl+A` → `Ctrl+C`。ツールに戻って `Ctrl+V` するとStart2を自動認識して読み込みます。**「② クリップボードから読み込む」** ボタンでも同じことができます

クリップボードAPIが使えないブラウザでも、通常の `Ctrl+V` のpasteイベントで読み込めます。必要なら画面の「クリップボード読込が使えない場合」を開き、JSONを貼り付けてボタンで読み込むこともできます。ファイルのダウンロードやアップロードは不要です。

読み込み成功後はIndexedDBに保存されるため、次回から再設定は不要です。新艦・新装備追加後に更新したい場合だけ、同じ手順で上書きしてください。

### データの流れ

```text

        ↓ 利用者本人が開いてコピー
利用者のクリップボード

```

## 現在の最適化方式（段階探索）

ブラウザのメモリ使用量を抑えつつ、5-2-1で実用上重要な順序をそのまま探索手順にしています。

### フェーズ1A：噴進弾幕100%を最優先

噴進弾幕可能艦だけを対象に、まず **12cm30連装噴進砲改二 + 機銃** だけで探索します。

1. 噴進砲改二が全員分ある場合は、各艦へ最低1本ずつ配る。
2. 機銃を使って噴進弾幕100%以上を目指す。
3. 全艦100%が可能なら、それを必須条件にする。
4. 全艦100%が不可能なら、**100%達成艦数 → 100%上限の発動率合計** の順で最大化する。
5. 同じ到達度なら、100%を大きく超える過剰装備や余分な噴進砲を避ける。

この段階では高角砲・電探・対空CIなどを混ぜません。噴進率を上げる仕事だけを機銃に限定することで探索空間を大幅に削減します。

### フェーズ1B：100%を維持して艦隊防空を増やす

フェーズ1Aで100%以上になった艦だけを再探索します。

- **噴進弾幕100%以上を絶対条件**として維持する。
- その制約内で、機銃の一部を高角砲・電探などへ置き換え、艦隊対空ボーナスを最大化する。
- 100%未達艦はフェーズ1Aの機銃構成を維持し、噴進率を落とさない。

つまり、まず自分自身を噴進弾幕で守り、その後の余力を艦隊防空へ回します。

### フェーズ2：非噴進弾幕艦の対空砲火を最適化

非噴進弾幕艦について、残った装備から対空装備構成を探索します。

- 現在対応している主要対空CIを考慮する。
- 加重対空と艦隊防空を考慮する。
- 5-2-Cの3敵編成を各1/3として計算する。
- 制空権喪失時Stage1の敵機損耗後、Stage2対空砲火を確率計算する。
- **敵攻撃機の期待残存数を最小化 = 期待撃墜数を最大化**する組み合わせを採用する。
- 同じ期待残存数なら、敵攻撃スロット全滅率、艦隊防空の順で比較する。

最終結果では参考値として、噴進弾幕・被ターゲット率・回避まで含めた艦隊無被弾率も表示します。ただしv1の装備探索そのものは、上記の段階探索の明確な優先順位で行います。

陣形は事前選択しません。艦数に応じて使用可能な陣形を自動で個別最適化し、陣形ごとの艦隊無被弾率を計算します。推奨は警戒陣を含む使用可能陣形すべてから「被弾率最小 = 無被弾率最大」の陣形を自動表示します。警戒陣が最良ならそのまま推奨し、イベント期間限定であることを併記します。3隻以下は単縦陣のみ、4隻は単縦陣・複縦陣・警戒陣、5隻以上は単縦陣・複縦陣・輪形陣・警戒陣を比較します。


### 陣形の自動比較

装備最適化時にユーザーが陣形を指定する必要はありません。フェーズ1A/1Bは陣形非依存なので1回だけ計算し、その結果を共有してフェーズ2を各陣形について計算します。結果画面では陣形ごとの「無被弾率 / 被弾率」をタブ表示し、クリックするとその陣形専用の装備配分・計算結果へ切り替わります。DeckBuilder JSONのコピー結果も、現在表示中の陣形の装備配分に追従します。

## 計算式

艦これ攻略Wiki「対空砲火」「12cm30連装噴進砲改二」の現行記載を基準にしています。

- 加重対空値: `A × floor(X / A)`
- `X = 素対空 + Σ(装備倍率×装備対空 + 改修係数×sqrt(★)) + 0.75×装備ボーナス対空`
- 各艦の艦隊対空ボーナス値: `floor(Σ(艦隊防空用倍率×装備対空 + 改修係数×sqrt(★)) + 0.5×装備ボーナス対空)`
- 艦隊防空値: `floor(陣形補正 × 各艦の艦隊対空ボーナス値合計) × (2/1.3)`（最後は切り捨てない）
- 割合撃墜率: `加重対空値 / 400`
- 噴進弾幕推定発動率: `((0.9×運 + 加重対空)/281)×100 + 複数積み補正 + 伊勢型補正`
- 単縦陣: 1.0 / 複縦陣: 1.2 / 輪形陣: 1.6 / 警戒陣: 1.1
- 割合撃墜: `floor((加重対空/400) × 敵スロット機数)`（成功率50%）
- 固定撃墜: `floor(((加重対空+艦隊防空) × 対空CI変動ボーナス)/10)`（成功率50%）
- 最低保証: `1 + 対空CI固定ボーナス`

### 5-2-Cの空襲評価

5-2-CはWiki記載の3編成を固定の仮想敵として使い、ユーザー指定により各パターン1/3で出現すると扱います。艦戦スロットは攻撃しないため、枯らす対象は敵艦爆/艦攻スロットだけです。

- 白ヲflagship: 艦爆32 / 艦攻27 / 艦攻5 → **3攻撃スロット**
- 通常ヲflagship: 艦攻32 / 艦爆32 → **2攻撃スロット**
- P1: 白ヲ1 → **[32, 27, 5] の3スロット**
- P2: 白ヲ1 + 通常ヲ1 → **[32, 27, 5, 32, 32] の5スロット**
- P3: 白ヲ2 → **[32, 27, 5, 32, 27, 5] の6スロット**

単純な平均スロット数だけで潰さず3編成を明示的に計算するため、「遭遇した編成の全攻撃スロットが0機になり、敵航空攻撃が発生しない確率」も最適化に使います。

5-2-1は**自艦隊制空値0＝制空権喪失固定**として評価します。Stage1では、制空権喪失時の敵機迎撃割合を `0% / 3.5% / 6.5% / 10%`（各25%）として確率分岐し、その残存機数にStage2対空砲火を適用します。最適化候補から航空機を除外するため、出力編成も制空値0の前提を維持します。

### 航空戦の回避・命中評価

艦これ攻略Wiki「命中と回避について」の現行推定式を使用します。通常艦隊に対する航空戦では攻撃側の命中項は95固定、航空戦時の陣形回避補正は全陣形1.0とされています。警戒陣の通常の回避ボーナスは航空戦には効かない一方、警戒艦へ攻撃が集中するターゲット補正は残るとされています。

- 基本回避項: `floor(素回避 + 装備回避 + sqrt(2×運))`
- 40未満: そのまま
- 40以上65未満: `floor(40 + 3×sqrt(基本回避項-40))`
- 65以上: `floor(55 + 2×sqrt(基本回避項-65))`
- 航空戦命中項: `95`
- `max(10, 95 - 回避項)` に疲労補正を掛け、96%でキャップ後、最終命中率は `floor(値)+1%` として扱います。
- 旗艦: cond49固定 → 疲労補正1.0
- 随伴: cond0固定 → 赤疲労補正1.4

`ev` も `aa` と同様に現在装備込み表示値として扱い、入力時装備の回避値を引いて素回避を推定し、最適化後装備の回避値を足し直します。

ターゲット率は通常時は均等、警戒陣では主力艦/警戒艦の再抽選を反映します。また航空攻撃でも「かばう」が発生するため、全艦小破未満で出撃する前提で単縦陣45%、複縦陣60%、輪形陣75%、警戒陣75%を反映しています。艦隊全体無被弾率の計算では、無被弾経路上は全艦が小破未満のままなのでこの扱いが成立します。

### DeckBuilder の `aa` の扱い

74式から出力される今回のDeckBuilderデータでは `aa` が現在装備込みの表示対空値になっているため、その値をそのまま「素対空」として加重対空計算に使うと、元の装備対空を二重計上します。

現版では、入力時の `aa` からコピー時点の装備の素の対空値を引いて `素対空推定値` を復元し、その値に最適化後装備の加重対空寄与を加えて再計算します。

例として Béarn（入力対空56）でコピー時点に 12cm30連装噴進砲改二を3本積んでいた場合、素対空推定は `56 - 8×3 = 32` です。この補正を入れないと噴進弾幕発動率を過大評価します。

## 現版の既知の制限

- 艦・装備の組み合わせで付く **装備ボーナス(対空)** はStart2だけでは完全に復元できないため、現版では未対応です。Wiki式上は加重対空へ0.75倍、艦隊防空側へ0.5倍で寄与します。そのため該当装備を使う艦では74式と数ポイントずれる可能性があります。
- 上記の理由で入力から復元する値はUI上も「素対空推定」と表示します。回避についても装備ボーナスは未対応のため「素回避推定」です。
- 対空CIは現在、**汎用CI・戦艦汎用・秋月型・Atlanta級・Fletcher級・摩耶改二**を実装しています。その他の艦固有CIは順次追加予定です。
- 対空CIの単体発動率はWiki練習ページに掲載された検証推定値を使用しています。2023/05/26以降の多重判定も推定仕様として扱います。
- 5-2-Cの敵編成そのものはWikiの3パターンを使用します。出現率についてWiki表では比率を確認できないため、現版はユーザー指定どおり各1/3です。
- 制空状態は5-2-1専用仕様として制空権喪失に固定しています。艦戦など航空機は最適化候補にしません。
- 3積み時の噴進弾幕補正はWiki記載の「+30%程度」を +30% として扱っています。
- 艦隊全体無被弾率は「全艦小破未満・燃料ペナルティなし」でCマスへ入る前提です。
- 艦隊全体無被弾率は噴進弾幕の航空戦中継続効果を考慮して発動結果を艦ごとに列挙します。
- 期待被弾艦数は、途中で他艦が被弾して「かばう」可能艦数が変わる二次効果を簡略化した補助指標です。主目的の「艦隊全体無被弾率」は無被弾経路のみを見るため、この簡略化の影響を受けません。
- 探索はブラウザで実用時間に収めるためビームサーチです。厳密な全組合せ総当たりではありません。探索幅は旧版より広げてあり、数秒程度かかる場合があります。

## 装備探索の優先制約（v1）

- 噴進弾幕可能艦へ噴進砲改二が全員分ある場合、各艦へ最低1本ずつ配ることを必須にします。
- その在庫条件で全噴進弾幕艦を100%以上にできるかは、まず噴進艦だけを対象にDFSで確認します。可能なら**全噴進艦100%以上を必須条件**に格上げし、その後に残った装備で非噴進艦を防御します。
- 非噴進弾幕艦が1隻でも混在する場合、対空候補を装備できる通常スロット・補強増設は原則として空けません。全スロットを埋めるだけの候補装備が物理的に足りない場合のみ、空きを許す探索へフォールバックします。
- 全艦が噴進弾幕可能で全員100%以上を確保できる場合は、不要な装備消費を避けるため空きスロットを許容します。

## 2026-09-05 探索安定化

- ビーム探索が序盤艦へ希少装備を集中し、後続艦に在庫を残せず「所持装備制約を満たす組合せを生成できませんでした」と誤判定する問題を修正。
- 候補集合に完全な在庫割当が存在するかをDFSで先に確認し、ビーム探索が枝刈りで失敗してもその完全解を最低保証として保持するよう変更。
- 同じ噴進達成度なら不要な2本目・3本目の噴進砲をビーム探索途中で軽く不利にし、1本ずつ配布する状態を残しやすくした。
- 混成艦隊で全スロット充足が本当に不可能な場合だけ、空き許容へフォールバックする。

## 2026-09-05 噴進100%優先・CI候補保持の再調整

- 噴進100%の可否判定から非噴進艦の装備消費を切り離し、「まず噴進艦を100%化 → 残りで防空」の順序を明確化。
- 候補装備の枝刈りを役割別に変更し、高加重対空機銃・高艦隊防空の高角砲・主要対空CI構成装備を別枠で保持。
- 100%達成後のビーム探索では噴進率の余剰を評価せず、対空CI候補と艦隊防空を優先して最終無被弾評価へ渡す。
- RenoをAtlanta級専用対空CI対象として艦名でも補完判定。

## v1 探索優先順位（2026-09-05修正）

噴進弾幕可能艦は、まず噴進砲改二を配布し、噴進弾幕100%達成を最優先する。
100%未達艦が残る間は、艦隊無被弾率や艦隊防空よりも、各艦の噴進率（100%上限）の合計を優先して100%へ近づける。
候補装備も噴進艦については加重対空を優先し、機銃を厚く保持する。
全噴進艦が100%になった後で、高角砲・対空電探・主要対空CIなどを使い、5-2-Cの艦隊無被弾率を最大化する。
Reno/Atlanta等の専用CI装備は候補枝刈りで消えないよう優先保持する。

## 2026-09-05 段階探索版

- 旧版の「全艦・全装備を同時にビーム探索」方式は、所持装備数が多い環境でOut of Memoryを起こすため廃止。
- フェーズ1Aは噴進砲改二＋機銃のみ、フェーズ1Bは100%維持下の艦隊防空、フェーズ2は非噴進艦の期待撃墜数、という3段階に分離。
- 各段階の候補数・ビーム幅も上限を設け、1回の展開で数百万状態をメモリに作らないよう変更。
- フェーズ2の結果表示に「期待撃墜機数」「敵残存攻撃機期待」を追加。
